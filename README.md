# ☕ Café Sunshine – Interactive 3D Café Website

Café Sunshine is a modern and interactive café website designed to give customers a beautiful and engaging online experience. It combines stylish visuals, 3D food models, smooth navigation, and useful features that make exploring a café easier.

## ✨ Features

- **Modern UI:** Clean, attractive, and responsive design for desktop and mobile devices.
- **3D Food Experience:** Interactive 3D food models using Three.js.
- **Digital Menu:** Browse café food and beverages with images and prices.
- **Shopping Cart:** Add menu items to your cart and place orders through WhatsApp.
- **Table Reservation:** Submit a table booking request directly through the website.
- **Photo Gallery:** Explore café and food photography.
- **Customer Reviews:** Display customer feedback and ratings.
- **Google Maps:** View the café location and get directions.
- **Google Sheets Integration:** Option to save order details to Google Sheets.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Three.js
- Google Apps Script

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Explore the website and its interactive features.

## ⚙️ Customization

Update `config.js` to change café details, menu information, contact details, and WhatsApp number.

## 🎯 Project Goal

The goal of this project is to create a creative digital café experience that combines modern web design, interactive 3D visuals, and convenient customer features.
